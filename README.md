# Diabetic Retinopathy Stage Detection — Computer Vision CW

Individual coursework: CNN + transfer learning classification of diabetic
retinopathy severity (5-stage, ICDR scale) on the APTOS 2019 Blindness
Detection dataset. Three architectures (EfficientNet-B3, EfficientNet-B0,
ResNet50) are trained under one identical pipeline and combined into a
soft-vote ensemble, with Grad-CAM explainability as the innovation
component.

## What's actually in this repo

- **One consolidated notebook** (`notebooks/ComputerVision_CW_LM_Navaratna_002_16114793.ipynb`)
  covers the full pipeline end to end: data exploration and smoke tests,
  preprocessing (dark-border crop, circular field-of-view mask, CLAHE),
  augmentation, model-level smoke tests, training all three architectures,
  evaluation, ensembling, and Grad-CAM. It is built as single-purpose cells
  rather than one long block per stage, so each step's
  output can be inspected on its own.
- **Trained and evaluated on Kaggle** (T4 GPU), since the dataset and
  compute live there already. See `outputs/` for the figures and result
  tables pulled from that run.

## Structure
- `notebooks/` — the single end-to-end pipeline notebook.
- `src/` — (optional) reusable functions pulled out of the notebook, if you
  choose to extract any for the code-quality write-up.
- `data/` — never committed (see `.gitignore`); the dataset lives on Kaggle,
  attached as a notebook input, not downloaded locally.
- `outputs/` — figures, model checkpoints, and result tables generated by
  the notebook, organised to mirror the notebook's own output folders
  (`figures/eda`, `figures/preprocessing`, `figures/augmentation`,
  `figures/training`, `figures/evaluation`, `figures/gradcam`, `models/`,
  `results/`).
- `report/figures_for_report/` — the curated subset of figures actually
  used in the PDF report (not every figure in `outputs/`, just the ones
  that made the final cut).

## Reproducing
- **Full training and evaluation:** open `notebooks/ComputerVision_CW_LM_Navaratna_002_16114793.ipynb`
  on **Kaggle Notebooks**, attach the APTOS 2019 dataset via "Add Input,"
  turn on a GPU accelerator and turn on the internet within the session options, and 
  run top to bottom. Expect roughly 1 hour and 20 mins
  total runtime (preprocessing cache build plus training three
  architectures).
- **Locally:** the notebook can be opened and read locally, but training
  three CNNs from scratch on a laptop is impractical, this project was
  designed to run on Kaggle's free GPU.
